# ADR-0007: 차트 완전 번역을 지원하지 않는다

- **상태**: 채택됨
- **날짜**: 2026-09-16

## 맥락

ADR-0006은 차트 번역을 미지원으로 명시하고 완전 지원(제목+카테고리+시리즈명)을
장기 과제로 미뤘다. 다시 따져보니 내장 엑셀 워크북 재작성 + 번역 후 차트
레이아웃 깨짐 검증이 필요하고, 차트 텍스트는 수동 번역으로 충분한 빈도다.
`PPTParser.count_skipped_shapes` 경고와 추출의 차트 표로 "어디까지 되는지"는
이미 보인다.

## 결정

차트 완전 번역을 하지 않는다 (wontfix). 차트가 있는 덱은 본문만 번역하고
차트는 원문 유지가 최종 동작이다.

## 결과

얻는 것: 범위 논쟁 종결. 워크북 재작성·레이아웃 검증이라는 큰 작업을 안 한다.
잃는 것: 차트 텍스트는 계속 수동 번역. 수요가 바뀌면 이 ADR을 뒤집는 새 결정이
필요하다.
