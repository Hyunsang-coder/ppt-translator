# Architecture Decision Records

이 프로젝트의 주요 결정을 시간순으로 기록한다. **CLAUDE.md와 `docs/`의 다른 문서는 "지금 어떻게 되어 있는가"만 쓰고, "왜 그렇게 됐는가"와 "예전엔 어땠는가"는 전부 여기로 보낸다.** 그래야 CLAUDE.md에 히스토리가 누적되지 않는다.

## 언제 ADR을 쓰나

다음 중 하나라도 해당하면 쓴다.

- 되돌리기 비싼 결정 — 배포 방식, 저장소 위치, 데이터 포맷, 외부 의존성 도입/제거
- 나중에 "왜 이렇게 했지?"가 나올 결정 — 자명해 보이지 않는 트레이드오프를 택한 경우
- 이전 결정을 뒤집는 변경 — 기존 ADR을 `대체됨`으로 바꾸고 새 번호를 딴다

쓰지 않는 것: 일상적인 버그 수정, 리팩터링, 라이브러리 버전 업, 커밋 메시지로 충분한 변경.

## 어떻게 쓰나

1. `0000-template.md`를 복사한다.
2. 파일명은 `NNNN-english-slug.md` — 번호는 다음 순번, slug는 영어 소문자 하이픈.
3. 본문은 한국어. 코드 식별자·경로·명령은 원문 그대로.
4. 아래 목록에 한 줄 추가한다.
5. 한 번 병합된 ADR의 본문은 고치지 않는다. 결정이 바뀌면 새 ADR을 쓰고 옛 것의 상태만 `대체됨 (ADR-NNNN)`으로 바꾼다.

## 상태

- `채택됨` — 현재 유효
- `대체됨 (ADR-NNNN)` — 다른 결정으로 교체됨
- `폐기됨` — 더 이상 해당하지 않음 (대체 결정 없음)
